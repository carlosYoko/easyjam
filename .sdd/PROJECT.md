# Project

## What This Is

EasyJam es un proyecto de aplicación web para acompañar canciones completas con guitarra rítmica simplificada, cómoda y sincronizada con YouTube. Actualmente solo existe documentación y planificación; no hay aplicación ni despliegue.

## Core Value

«No necesitas tocar una canción exactamente como el artista original para disfrutar tocándola de principio a fin».

## Current State

Investigación documental realizada; ninguna prueba de reproducción real ni tarea ejecutada o capacidad validada. Vídeo técnico inicial M7lc1UVf-VE, guía ficticia identificada y objetivo Chrome/Chromium escritorio; inserción real aún no comprobada. Canción y arreglo autorizados para S02 pendientes. Modo manual, una tarea cada vez; no auto ni avance a S02.

## Architecture / Key Patterns

Base ejecutable aprobada específicamente para S01: Vue 3 + Vite + TypeScript estricto, Vitest, Playwright, pnpm y Node LTS compatible. Versiones estables exactas pendientes de selección/documentación en T01, con pnpm-lock.yaml reproducible. Arquitectura modular y puertos/adaptadores solo donde aporten valor; no hay implementación todavía. ADR-001 y constitución no ratificados globalmente. Renderizador, bibliotecas musicales, representación temporal y optimizador siguen abiertos.

Una canción, dificultad fácil, guitarra de seis cuerdas, E A D G B E, trastes 0–12 y quintas de dos notas como base. Sin catálogo, campo URL, backend, cuentas o infraestructura anticipada. Derechos y políticas son condición obligatoria.
